INKRAIL FOR WINDOWS
Paper, ink, and a little room to write.
1. Use the x64 ZIP for an Intel or AMD PC, or arm64 for an ARM-based PC.
2. In File Explorer, choose Extract All. Keep the whole folder together.
3. Open Inkrail.exe. The portable app includes its .NET runtime.
4. Microsoft Edge WebView2 Evergreen Runtime must already be installed.
   If Inkrail reports it missing, Microsoft's official downloads are here:
   https://developer.microsoft.com/microsoft-edge/webview2/
   The desk works offline once the runtime is available.

At your desk:
  Ctrl+N                 New letter
  Ctrl+Shift+O           Letter box (search, rename, trash and restore)
  Ctrl+,                 Make it yours
  Ctrl+B / I / U         Bold / italic / underline
  Ctrl+\                 Clear inline formatting
  Ctrl+Shift+F           Focus mode
  Ctrl+Alt+L             Night writing (or click the capsule)
  Ctrl+Shift+M           Sound on / off
  Ctrl+O                 Import text or Markdown
  Ctrl+S                 Save now (writing also autosaves)
  Ctrl+Shift+E           Export text
  Alt+F or the top …     File menu, including Export Markdown

Libraries:
  Default letters: %APPDATA%\Inkrail\Library\Letters
  Preferences:    %APPDATA%\Inkrail\preferences.json
  WebView2 cache: %LOCALAPPDATA%\Inkrail\WebView2

To move your current Windows library, use Make it yours > Storage > Change
location and select an empty folder. Inkrail copies and verifies the library;
your old copy remains in place. Deleted letters are restorable for 30 days.
When storage is unavailable, export a copy before quitting. Keep independent
backups; do not point multiple running copies of Inkrail at the same folder.

To bring over a Mac library, first back it up. With Inkrail closed on both
computers, copy the entire library (Letters, Recently Deleted, and Recovery
if present) into a NEW/EMPTY Windows library folder at the default path
above, before first launch. Do not merge, overwrite an existing collection,
or copy per-machine preferences. For individual letters, use Markdown.

Optional native smoke test:
  Close the test copy of Inkrail. From PowerShell in this extracted folder,
  run .\Check-Inkrail.ps1 if your organization's script policy permits.
  It opens the app with disposable new and legacy profiles. It checks typing,
  formatting, renaming a letter, moving it to Recently Deleted, restoring it,
  saving on close, and reopening the saved letter with its settings.
