i

macOS says the app can't be opened?

Inkrail is currently not notarized by Apple. In Applications, Control-click Inkrail.app → Open → Open. If that option isn't available, try opening it once, then go to System Settings → Privacy & Security → Open Anyway. This is a first-launch step, not something you'll need to repeat every time.

01

Saved on your Mac

By default, the library lives in:

~/Library/Application Support/Inkrail/
02

Change location anytime

Go to Make it yours → Storage → Change Location and choose a new, empty folder. Keep a separate backup of your library.

03

Take your writing with you

Export a letter as .md or .txt. Deleted letters can be restored from Recently Deleted for 30 days.

Inkrail's internal library uses its own saved letter files; it does not automatically save each letter as a Markdown document. Choosing a synced folder does not make multi-device syncing an officially supported feature. Read about storage & recovery ↗

GOOD TO KNOW

A few more
things.

Can't find what you're looking for? Ask on GitHub ↗

Is Inkrail free?+

Yes. Inkrail is free and open source under the MIT license. There are no accounts or subscriptions.

Which Macs are supported?+

Inkrail requires macOS 13 Ventura or later. Download the current build from the releases page. There is no Windows or iPad app in this release.

Does Inkrail sync with iCloud?+

Inkrail is local-first and has no built-in cloud sync. You can choose a storage folder, but iCloud Drive compatibility and simultaneous edits across Macs are not guaranteed or officially supported. Export your writing and maintain backups.

Can I use Markdown?+

Yes. Inkrail supports Markdown-like formatting shortcuts as you type, can import text or Markdown, and lets you export individual letters as Markdown or plain text. Its internal library is not a folder of native .md files.

Can I turn off the typewriter sounds or decorations?+

Of course. Sound is optional, and Focus Mode makes the writing area wider and clears the desk decorations. Use ⇧ ⌘ F for Focus Mode and ⇧ ⌘ M to toggle sound.

Can I build Inkrail from source?+

Yes. The project is written in Swift and open source. Building requires macOS 13+ and Apple’s Swift 5.9+ developer tools. See the build instructions on GitHub ↗.
