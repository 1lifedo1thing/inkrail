YOUR FIRST FIVE MINUTES

From download
to first draft.

Choose the instructions for your computer, then make the desk your own.

01 —

Install on Mac.

The v0.1.1 download runs on Apple silicon with macOS 13 or later. Unzip it and drag Inkrail.app into Applications. On an Intel Mac, build from source.

Download for Mac ↗
02 —

Install on Windows.

Install from the Microsoft Store and open Inkrail from Start. For a portable copy on an Intel or AMD x64 PC, extract the v0.1.1 Windows x64 ZIP and open Inkrail.exe.

Get it from the Microsoft Store↗
03 —

Make it yours.

Press ⌘ , on Mac or Ctrl+, on Windows to pick your paper, typewriter, desk, ink, and evening light.

Explore shortcuts ↗
04 —

Start your story.

Press ⌘ N on Mac or Ctrl+N on Windows for a new letter. Your desk shows live word and character counts and saves as you write. Choose Markdown to keep the formatting or plain text for the words.

Your words, your files ↗

THE IMPORTANT DETAILS
01

Find your library

Mac · Writing → Show Local Files

~/Library/Application Support/Inkrail/

Windows · Make it yours → Storage → Show in File Explorer

%APPDATA%\Inkrail\Library
02

Change location anytime

Go to Make it yours → Storage → Change Location and choose a new, empty folder. Keep a separate backup of your library.

03

Take your writing with you

To move a letter between Mac and Windows, export it as Markdown (.md) and import it on the other computer. Use plain text (.txt) for a copy of the words. Deleted letters can be restored from Recently Deleted for 30 days.

The library holds your original letters and recovery files. Read about storage & recovery ↗

GOOD TO KNOW

A few more
things.

Can't find what you're looking for? Ask on GitHub ↗

Is Inkrail free?+

Yes. Inkrail is free on Mac and Windows. The app source is available under the MIT license. There are no accounts or subscriptions.

Which computers can run Inkrail?+

The v0.1.1 ZIPs are for Apple silicon Macs running macOS 13 or later and Windows x64 PCs. You can build locally on an Intel Mac or build the Windows app for ARM64. The Store lists its own Windows system requirements.

How do I find a letter?+

Open the letter box and search for a private title or any words from the letter. Letters are grouped by the month of their last edit, newest first. You can also search in Recently Deleted. Reopening Inkrail brings back your last selected letter.

Can I use Markdown?+

Type **bold**, _italic_, ***bold italic***, or ~~strikethrough~~. Backticks mark inline code. One to six hashes followed by a space create a heading. The hashes disappear when you type the heading text. Quote and list markers stay visible. Copy and paste between letters keeps the emphasis. You can import and export Markdown or plain text.

Which features are in development?+

Work after v0.1.1 adds personal wax seals, Maker’s mark embossing, decorative margin styles, and a universal Mac app for Intel and Apple silicon. In the development build, Export Letter as PDF… keeps the paper, ink, and line wrapping. Decorative margins and embossing appear on the first sheet, and your seal appears on the last. Markdown also preserves a seal’s inscription, shape, and color when you import it back into Inkrail.

Can I sync letters between computers?+

Mac and Windows keep separate local libraries. For individual letters, export Markdown on one computer and import it on the other. If you choose iCloud Drive as a library location on Mac, iCloud handles folder syncing. Keep a separate backup and use one copy of Inkrail at a time with that library.

Can I turn off the sounds or desk decorations?+

Yes. Click the speaker to mute the typewriter. Focus Mode hides the desk objects. Under Make it yours → Desk, choose whether the sheet widens in Focus Mode.

Can I build Inkrail from source?+

Build the Swift app on macOS 13 or later with Apple’s Swift 5.9+ developer tools. Use the .NET 10 SDK and Python to package the Windows x64 and ARM64 apps. Read the build instructions on GitHub ↗
