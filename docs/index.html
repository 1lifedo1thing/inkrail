YOUR FIRST FIVE MINUTES

From download
to first draft.

Choose the instructions for your computer, then make the desk your own.

01 —

Install on Mac.

On an Apple silicon Mac running macOS 13 or later, open Inkrail.zip in Finder. Drag Inkrail.app into Applications and open it.

Download for Mac ↗
02 —

Set up on Windows.

On a 64-bit Intel or AMD PC, download Inkrail-Windows-x64.zip. In File Explorer, choose Extract All, then open Inkrail.exe. Keep the extracted files together. This build is unsigned.

Download for Windows x64↗
03 —

Make it yours.

Press ⌘ , on Mac or Ctrl+, on Windows to pick your paper, typewriter, desk, ink, and evening light.

Explore shortcuts ↗
04 —

Start your story.

Press ⌘ N on Mac or Ctrl+N on Windows for a new letter. Inkrail saves automatically. Export as Markdown or plain text whenever you like.

Your words, your files ↗
i

First launch on your computer

If macOS blocks the unnotarized app, Control-click Inkrail.app and choose Open. After an attempted launch, you can also choose Open Anyway in System Settings → Privacy & Security. Mac setup help ↗

The first time you open Inkrail.exe, Microsoft Defender SmartScreen may show Windows protected your PC. If it does, select More info to reveal Run anyway at the bottom of the same dialog. Select it to open Inkrail. Windows normally remembers this choice for that copy.

If Inkrail reports a missing Microsoft Edge WebView2 Evergreen Runtime, install the runtime and open Inkrail.exe again. Get WebView2 from Microsoft ↗

Find your library

~/Library/Application Support/Inkrail/

Windows · Make it yours → Storage → Show in File Explorer

%APPDATA%\Inkrail\Library
02

Change location anytime

Go to Make it yours → Storage → Change Location and choose a new, empty folder. Keep a separate backup of your library.

03

Take your writing with you

To move a letter between Mac and Windows, export it as Markdown (.md) and import it on the other computer. Use plain text (.txt) for a copy of the words. Deleted letters can be restored from Recently Deleted for 30 days.

Inkrail keeps its own local letter files. Export a letter when you want a Markdown copy. Read about storage & recovery ↗

GOOD TO KNOW

A few more
things.

Can't find what you're looking for? Ask on GitHub ↗

Is Inkrail free?+

Yes. Inkrail is free on Mac and Windows x64. The Mac source is available under the MIT license. There are no accounts or subscriptions.

Which computers can run Inkrail?+

The Mac download runs on Apple silicon with macOS 13 Ventura or later. The unsigned Windows x64 app runs on PCs with 64-bit Intel or AMD processors. It works offline once the Microsoft Edge WebView2 Evergreen Runtime is installed.

Can I sync letters between computers?+

Mac and Windows keep separate local libraries. For individual letters, export Markdown on one computer and import it on the other. If you choose iCloud Drive as a library location on Mac, iCloud handles folder syncing. Keep a separate backup and use one copy of Inkrail at a time with that library.

Can I use Markdown?+

Yes. Inkrail supports Markdown-like formatting shortcuts as you type, can import text or Markdown, and lets you export individual letters as Markdown or plain text. Its internal library is not a folder of native .md files.

Can I turn off the typewriter sounds or decorations?+

Of course. Sound is optional, and Focus Mode makes the writing area wider and clears the desk decorations. For Focus Mode, press ⇧ ⌘ F on Mac or Ctrl+Shift+F on Windows. To toggle sound, use ⇧ ⌘ M or Ctrl+Shift+M.

Can I build Inkrail from source?+

This repository contains the Swift source for the Mac app. To build it, use macOS 13+ and Apple’s Swift 5.9+ developer tools. The Windows x64 app is available as a portable ZIP. See the build instructions on GitHub ↗.
